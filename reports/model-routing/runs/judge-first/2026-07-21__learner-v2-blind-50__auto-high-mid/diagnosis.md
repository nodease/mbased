1. `report.md`가 상위 재판정 비용을 자동 총비용에 포함하지 않는다.
2. 자동 라우팅 정확도 40건 중 32건이 `unclassified`다. 기대 모델 등급 목록이 `gpt-5.4-mini` 등 실제 선택 alias를 충분히 분류하지 못해 현재 정확도 지표는 판단 근거로 쓰기 어렵다.

## 우선 수정 권고

1. **P1 비용 집계**: `routing_judge`와 `routing_adjudicator`, 실패한 후보 호출 비용까지 자동 경로 총비용에 포함한다.
2. **P1 저가 후보 capability**: JSON 출력에서 `responses_incomplete`가 반복된 `gpt-5-nano`와 `gpt-5-mini`를 현재 설정의 유효 후보에서 제외하거나 max output/reasoning 설정을 모델별로 맞춘 뒤 재검증한다.
3. **P1 안전 gate**: 재판정을 생략한 저위험 요청에서도 후보의 실제 계약 통과 증거가 없으면 약한 모델을 바로 사용하지 않는다.
4. **P1 로컬 학습**: 모든 요청을 `(2,2,2)`로 예측하는 붕괴를 해결한 뒤에만 learner version 발행을 허용한다. 현재 gate가 version 발행을 막은 것은 정상이다.
5. **P2 벤치마크 분류**: dated alias를 canonical model family로 정규화하고, 기대 난이도별 허용 모델 목록에 현재 catalog를 반영한다.
6. **P2 중단 복구**: 실험 프로세스 종료 시 실행 중 run/node를 `STOPPED` 또는 `FAILED`로 닫는 정리 절차를 추가한다.
