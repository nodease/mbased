# 저가 모델 방어 실험 비교 보고서

## 결론

저가 모델 과다 선택을 막는 변경은 유지할 가치가 있다. 동일한 첫 25개 요청에서 평균 품질과 품질 통과율이 모두 개선됐고, 사전 난이도 가설보다 낮은 모델을 고른 사례는 0건이었다. 비용 절감 폭은 줄었지만 고가 모델 고정 대비 59.1%를 절감했다.

30건을 모두 실행하지는 않았다. `gpt-5-mini`가 두 번 `responses_incomplete`를 반환해 설정한 이상 신호 중단 조건에 따라 25건에서 멈췄다. 두 요청은 `gpt-4.1` fallback으로 복구돼 workflow와 JSON 계약은 모두 성공했다.

## 변경 내용

1. 모든 공식 routing 모델에 0~3 범위의 초기 점수를 명시했다.
2. 요청의 작업 복잡도, 판단 영향도, 근거 종합도 평균과 중요 축 하한을 조합해 최소 모델 점수를 계산했다.
3. 답변 생성 작업은 JSON 출력이어도 최소 `gpt-4.1-mini` 수준을 요구한다.
4. Judge 판정이 불확실하면 일반 요구 점수보다 0.35 높은 안전 하한을 적용한다.
5. 안전 하한을 만족하는 모델이 없으면 configured fallback을 그대로 쓰지 않고, 현재 실행 가능한 모델 중 가장 강한 모델을 선택한다.
6. 실제 provider 실패 시 사용할 두 번째 모델도 같은 안전 기준으로 정한다.

순수 구조 추출 작업은 위 생성형 응답 하한을 적용하지 않아 저가 모델을 계속 사용할 수 있다.

- `gpt-4o-mini` 선택: 0회
- 사전 난이도 가설 적중: 24/25

## 남은 위험

`gpt-5-mini`는 25건 중 2건에서 `responses_incomplete`가 발생했다. 실험 graph의 `max_tokens`는 1,400이며 두 요청은 fallback으로 복구됐다. 이번 변경은 저가 모델 선택 방어가 목적이므로 출력 한도 정책은 함께 수정하지 않았다. 다음 검증 전에는 생성형 JSON 응답의 모델별 출력 한도와 reasoning token 사용을 별도 회귀 테스트로 다루는 것이 필요하다.

또한 품질 통과율 60%는 개선됐지만 제품의 최종 품질 기준으로 보기에는 낮다. 현재 결과는 “저가 모델 과다 선택을 줄이는 방향이 유효하다”는 증거이며, 사람 검수 없이 절대 품질을 보장하는 결과는 아니다.
