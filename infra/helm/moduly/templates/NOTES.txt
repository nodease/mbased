🚀 Getting Started:

1️⃣  Check deployment status:
   
   kubectl get pods -n {{ .Release.Namespace }}
   kubectl get svc -n {{ .Release.Namespace }}

2️⃣  Wait for all pods to be ready:
   
   kubectl wait --for=condition=ready pod \
     -l app.kubernetes.io/instance={{ .Release.Name }} \
     -n {{ .Release.Namespace }} \
     --timeout=300s

{{- if not .Values.ingress.enabled }}

3️⃣  Access the application (Port Forwarding):

   # Frontend (Web UI)
   kubectl port-forward -n {{ .Release.Namespace }} \
     svc/{{ include "moduly.fullname" . }}-frontend 3000:3000 &
   
   # Backend API
   kubectl port-forward -n {{ .Release.Namespace }} \
     svc/{{ include "moduly.fullname" . }}-gateway 8000:8000 &

   Then open:
   - Web UI:  http://localhost:3000
   - API Docs: http://localhost:8000/api/docs

{{- else }}

3️⃣  Access the application (Ingress):

   {{- range .Values.ingress.hosts }}
   - https://{{ .host }}
   {{- end }}

{{- end }}

     -l app.kubernetes.io/component=worker \
     -f

View all services:
   kubectl get all -n {{ .Release.Namespace }} \
     -l app.kubernetes.io/instance={{ .Release.Name }}
