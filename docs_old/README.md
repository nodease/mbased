# Nodease Legacy Documentation Archive

Status: Archived
Authority: Historical Reference
Source of Truth: No

`docs_old/` is a temporary archive of pre-restructure documentation and reverse-engineering notes. It is not the active documentation root.

The active documentation root is [`../docs/`](../docs/). When `docs_old/` conflicts with `docs/`, `AGENTS.md`, or current code, use `docs/` and current code as the governing source.

## Usage

- Use this directory only for background research, migration recovery, or historical comparison.
- Do not treat `Source of Truth: Yes` metadata inside archived child documents as current authority. Those values were preserved from the pre-restructure documentation set.
- Do not add new product, architecture, API, data model, or feature requirements here.
- When content is migrated into `docs/` and verified against code, prefer updating or deleting the corresponding archived source rather than extending this archive.

## Migration Rule

`docs_old/` can be deleted after the active `docs/` documents absorb the required content and code comparison is complete. The original archive remains recoverable through git history.
